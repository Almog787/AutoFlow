## 🇮🇱 עברית (Hebrew)

### הפכו את האתר שלכם למכונה שמייצרת לקוחות
**AutoFlow** היא סוכנות דיגיטל ואוטומציה עסקית המתמחה בבניית אתרים חכמים ואוטומציה של תהליכי עבודה. אנחנו בונים מערכות תפעוליות שמייצרות לידים, חוסכות שעות עבודה ידניות ומסדרות את הנתונים ישירות במערכות הניהול שלכם.

#### 🛠 מה אנחנו עושים?
* **פיתוח אתרים בהתאמה אישית:** אתרי תדמית, דפי נחיתה וחנויות איקומרס מהירות וממירות.
* **אוטומציה עסקית (Make / Zapier / Google Apps Script):** חיבור האתר למערכות ה-CRM, הנהלת חשבונות ויומנים.
* **טפסי לידים וסנכרון מלא:** קליטת פרטי לקוחות והזרמתם ישירות ל-Google Sheets / CRM בזמן אמת.
* **הגנה מובנית מספאם:** מנגנון Honeypot סמוי לסינון בוטים ופניות סרק.

#### 📊 מערכת ה-CRM המחוברת לטופס
טופס יצירת הקשר באתר מחובר ישירות ל-Google Sheets באמצעות Webhook של **Google Apps Script**:
1. **לידים נכנסים:** תאריך ושעה, שם מלא, טלפון, פירוט האתגר, וצ'קבוקס "טופל? (V)".
2. **דשבורד CRM:** סה"כ לידים, כמות לידים שטופלו, לידים הממתינים לטיפול, ואחוז טיפול כולל.

## 🇺🇸 English Version

### Turn your website into a client-generating machine
**AutoFlow** is a digital boutique agency specializing in building smart websites and business workflow automations. We design operational systems that save time, eliminate repetitive manual data entry, and streamline your operations.

#### 🛠 Core Capabilities
* **Custom Web Development:** High-converting landing pages and fast corporate websites.
* **Workflow & CRM Automation:** Automated routing of leads directly to Google Sheets or custom CRMs.
* **Multi-Language Architecture:** Seamless bilingual experience (Hebrew RTL & English LTR).
* **Anti-Spam Protection:** Integrated honeypot fields ensuring clean, bot-free inquiries.

#### 🚀 Technical Architecture
* **Frontend:** Clean Semantic HTML5, Modular CSS3, Modern Vanilla JavaScript (ES Modules).
* **Backend:** Node.js & Express server with `/api/lead` proxy and static asset handling.
* **SEO & Metadata:** Schema.org JSON-LD (`ProfessionalService`, `FAQPage`), OpenGraph, Twitter Cards, Canonical links.
* **Lead Ingestion:** Google Apps Script Web App Webhook (`POST` with JSON payload).
